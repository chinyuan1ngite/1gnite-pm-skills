# 参考图风格生成流程

## 一、确认参考图

1. 收集用户本次附加或明确指定的全部参考图；用户未提供且任务为汇报图片时，按 `style-reference-catalog.md` 选择内置参考图。
2. 本地参考图必须先进行视觉检查；对话附件必须完整传入本次图片生成请求。
3. 用户指定各参考图用途时按其说明执行；未指定时，将第一张作为主风格参考。
4. 用户提到参考图但没有提供可访问图片时，停止生成并请用户重新附加或提供路径。
5. 不扫描项目中的其他图片；内置参考集以外的项目文件必须由用户明确指定。

## 二、提取风格特征

从参考图提取以下高层特征，并转写为生图提示词：

- 整体气质与使用场景；
- 主色、辅助色、背景色和明暗关系；
- 栅格、分栏、留白和视觉重心；
- 标题、正文、数字和辅助信息的层级；
- 卡片、表格、图表、按钮和导航的形态语言；
- 圆角、边框、阴影、渐变、纹理和光感；
- 信息密度、对齐方式和阅读节奏。

不要把参考图中的具体业务内容当作风格特征。

## 三、建立新构图

- 根据用户的新主题和内容重新组织页面，不复刻参考图的具体页面和独特构图。
- 保留可概括的视觉语言，例如“冷色低饱和”“细边框容器”“高密度三栏布局”。
- 排除参考图中的 Logo、品牌名称、水印、人物、业务文字、数字、图标组合和专有标识。
- 参考图与用户文字要求冲突时，以用户本次文字要求为准。
- 参考图与 Skill 的安全、事实和项目隔离边界冲突时，以 Skill 边界为准。

## 四、多参考图规则

- 主风格参考：决定整体气质、配色和主要布局语言。
- 配色参考：只提供色彩关系，不决定构图。
- 布局参考：只提供分区和阅读节奏，不复制内容。
- 组件参考：只提供卡片、表格、图表或导航的形态语言。
- 用户未分配角色时，第一张为主风格，其余依次作为配色、布局和局部质感补充。
- 使用内置参考集时最多选择两张，优先保持一种清晰的主风格，避免四张图片同时输入造成风格混杂。

## 五、优先级

1. 用户本次明确提供或指定的参考图。
2. `style-reference-catalog.md` 中与汇报结构匹配的内置参考图。
3. `visual-guidelines.md` 中的文字默认规范。

## 六、生成检查

- 新画面是否与用户主题一致，而不是参考图内容的改写。
- 是否体现了参考图的主要视觉特征。
- 是否已排除 Logo、品牌名称、水印和参考图业务数据。
- 是否仍保持正面平视、非截图、无浏览器外框和无设备模型。
- 是否没有新增未经用户提供的业务规则和精确数字。
