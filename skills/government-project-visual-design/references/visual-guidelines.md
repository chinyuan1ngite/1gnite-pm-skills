# 某政务项目视觉设计规范

## 一、总体定位

- 视觉关键词：现代政务、专业可信、清晰克制、数字化、中高信息密度。
- 输出独立于项目 HTML 原型，不复刻 `common.css`，不以截图作为生成方式。
- 画面应像完成度较高的视觉设计稿，不像营销落地页、数据大屏或概念艺术海报。
- 不使用或生成 Logo、品牌名称及水印；参考图中的相关元素也不得带入新画面。
- 用户提供参考图时，参考图的高层视觉特征优先于本文件的默认色彩和构图建议，但禁止项始终有效。
- 汇报图片未提供参考图时，从 `assets/style-references` 中按 `style-reference-catalog.md` 选择匹配风格；高保真页面概念图不自动使用该参考集。

## 二、默认色彩

| 用途 | 建议颜色 |
| --- | --- |
| 深色基底 | 深海军蓝 `#0B1F3A` |
| 主色 | 政务蓝 `#155EEF` |
| 辅助强调 | 青绿色 `#0EA5A8` |
| 页面背景 | 雾灰白 `#F5F7FA` |
| 内容容器 | 白色 `#FFFFFF` |
| 主文字 | 深灰 `#1F2937` |
| 成功、提醒、风险 | `#16A34A`、`#D97706`、`#DC2626` |

允许根据主题调整明度与比例，但不要同时引入大量高饱和颜色。

## 三、字体与信息层级

- 使用清晰、现代的中文无衬线字体观感。
- 标题、关键指标、结论、正文和辅助信息至少形成四级层级。
- 核心数字可以放大，但不要采用夸张的数据大屏字体。
- 控制单张图片中的精确中文数量，避免细小、密集、难辨识文字。

## 四、高保真页面概念图

- 默认比例为 16:9，采用正面平视、完整画布构图。
- 页面可以重新探索导航、内容结构、卡片、表格、图表和状态表达，不受现有原型样式限制。
- 保持标准 B 端产品的可理解性，优先使用常见导航、筛选、指标、列表、详情和操作区形态。
- 使用克制的圆角、阴影和渐变；容器层级不超过三个主要层次。
- 不出现浏览器地址栏、标签页、操作系统边框、显示器、手机、键盘、人物或手持设备。
- 不使用透视倾斜、三维悬浮、玻璃拟态堆叠、霓虹赛博风或不规则异形组件。

## 五、汇报图片

- 默认提供 16:9 会议汇报图；用户提出移动端传播时使用 3:4 竖版。
- 推荐结构：主题标题、核心结论、关键指标、进展或问题、风险与下一步。
- 每张图只表达一个中心主题，核心结论不超过三项。
- 图表使用简洁的柱状、折线、环形、进度或流程关系，不制造虚假精确度。
- 装饰元素服务于分区和阅读引导，不使用无业务含义的大面积插画。

## 六、禁止项

- 禁止营销海报、地产广告、炫技数据大屏和节庆宣传风格。
- 禁止大面积渐变、过量发光、过度圆角、厚重阴影和密集装饰图标。
- 禁止把随机生成的中文、数字、徽标或政策名称表现为真实内容。
- 禁止使用项目或参考图中的 Logo；人员信息、业务数据和历史截图仅在用户明确指定时作为内容来源。
- 禁止复制参考图中的 Logo、品牌识别、具体业务文字、人物形象、数据和独特页面构图。
