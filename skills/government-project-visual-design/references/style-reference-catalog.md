# 内置汇报图参考集

## 使用规则

- 仅用于汇报图片，不默认用于高保真页面概念图。
- 用户本次提供的参考图优先于本参考集。
- 根据汇报内容结构选择一张主参考图；只有同时需要另一种局部视觉语言时才增加一张辅助参考图。
- 参考图只提供配色、构图逻辑、信息层级、组件质感和图形语言，不提供业务内容。
- 不复制任何 Logo、品牌名称、水印、人物、原有文字、数字和独特页面构图。

## 自动选择

- 出现“能力、模块、引擎、组成、体系总览”时，优先选择参考-01。
- 出现“完整说明、全景图、多个章节、操作指南、制度解读”时，优先选择参考-02。
- 出现“分层、架构、主体、身份、角色、层级关系”时，优先选择参考-03。
- 出现“现状与目标、痛点与方案、改革方向、优化前后”时，优先选择参考-04。
- 无法判断且用户只要求“采用默认汇报风格”时，使用参考-01。
