# 数据大屏高保真概念图规范

## 一、输出定位

- 生成数据大屏、领导驾驶舱、运行态势或业务监测的视觉概念稿。
- 只表达整体布局、信息层级、图表语言和视觉氛围，不代表真实数据分析结果。
- 与 HTML 原型完全分离，不读取或继承 `common.css`，不通过浏览器截图生成。

## 二、画布与构图

- 默认使用 16:9；用户明确要求超宽指挥屏时使用 32:9。
- 使用正面平视的完整设计画布，不出现显示器、会议室、指挥中心空间、人物或透视展示模型。
- 推荐结构：顶部标题与全局状态、核心指标带、中心主视图、左右分析区、底部趋势或事件区。
- 保持明确栅格、对称或近似对称的视觉稳定性，避免面板数量失控。

## 三、布局模式

- 中心指标型：中央突出核心指标和总体态势，左右放趋势、结构和风险。
- 中心地图型：中央放用户提供或明确允许的区域示意，左右放指标与排行；没有地图来源时只做抽象区域分布，不伪造行政边界。
- 多面板分析型：按照指标、趋势、结构、进度和预警形成稳定网格。
- 流程监测型：中央呈现流程或运行链路，周边展示节点指标、异常和事件。

## 四、默认视觉方向

- 使用深海军蓝到深蓝的低饱和背景，青蓝作为主要高亮，绿色、橙色、红色仅表达状态。
- 使用细边框、轻量光晕、克制渐变和低透明网格；保留足够暗部空间。
- 图表以折线、柱状、环形、进度、分布和关系图为主，保持统一线宽和颜色语义。
- 标题、核心指标、模块标题、图表标签和辅助信息形成清晰层级。

## 五、内容与数据边界

- 只使用用户提供的指标名称、模块名称、区域名称、时间范围和精确数值。
- 用户未提供数据时，使用无刻度趋势、抽象柱形、占位环图或弱化的 `--`，不要生成随机数字、比例、排名和日期。
- 用户未提供地图或行政区边界来源时，不生成看似精确的真实地图。
- 需要精确中文、数字、坐标轴和图表一致性时，提示该输出属于图片概念稿，不能替代真实可视化实现。

## 六、禁止项

- 禁止大面积霓虹、密集发光边框、无意义粒子、科幻舱体和赛博游戏界面。
- 禁止堆叠大量小面板、装饰性仪表盘、伪三维地球和无数据依据的地图热点。
- 禁止使用或生成 Logo、品牌名称、水印和人物形象。
- 禁止套用内置汇报图参考集，除非用户明确指定其中某张仅作为局部风格参考。
- 禁止把生成结果写回 PRD、台账、测试材料或真实统计报告。

## 七、生成检查

- 画面是否为正面平视的完整大屏，而不是设备或房间效果图。
- 核心指标、中心主视图和辅助分析区是否层级清晰。
- 是否只使用了用户提供的业务模块和精确数据。
- 是否避免随机数字、虚假地图、Logo 和过度科技装饰。
- 是否标明或体现“视觉示意”，不让图片被误认为真实运行数据。
