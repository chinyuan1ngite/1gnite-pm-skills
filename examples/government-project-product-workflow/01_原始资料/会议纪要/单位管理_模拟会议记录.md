# 某政务项目 · 单位管理模拟会议记录

本记录为公开演示编写。发言角色、议题和结论均为合成示例。

| 记录 | 发言角色 | 发言摘要 |
| --- | --- | --- |
| 记录-001 | 业务代表 | 管理员要能按条件找单位，清空条件后恢复默认列表，数据多时可以翻页查看。演示可以先用“示例单位甲”和“示例单位乙”。 |
| 记录-002 | 产品代表 | 新增、编辑和状态维护用同一套表单，保存后列表应显示本次变更。表格列可调整，刷新时重新读取列表。本次演示按这几项准备。 |
| 记录-003 | 测试代表 | 列表加载失败要能重试，界面需要区分失败和无数据。无页面权限时要有反馈，服务端也要拒绝返回单位数据。 |
| 记录-004 | 业务代表 | 禁用单位后成员能否登录、能否继续办理，留到权限专题确认。这轮只验单位状态在列表中的变化。 |
| 记录-005 | 产品代表 | 查询、维护和异常处理按本轮共识整理。单位删除留待另行评审。 |
